# SC-100 Cybersecurity Architect Labs

Hands-on labs for the Microsoft SC-100 Cybersecurity Architect certification, covering compliance, governance, and security design on Microsoft cloud.

All labs were completed in a training environment with a fictional company. Tenant IDs, account details, and credentials are covered or left out of the screenshots.

## Labs

* [ISO 27001 Compliance Assessment with Microsoft Purview Compliance Manager](https://github.com/nocphonokwanda73-cyber/sc-100-cybersecurity-architect-lab/blob/main/iso27001-compliance-assessment.md)
* [Data Classification Framework with Microsoft Purview](https://github.com/nocphonokwanda73-cyber/sc-100-cybersecurity-architect-lab/blob/main/data-classification-framework.md)
* [Retention Policies with Microsoft Purview](https://github.com/nocphonokwanda73-cyber/sc-100-cybersecurity-architect-lab/blob/main/retention-policies.md)

## Skills shown

* Creating a compliance assessment against ISO 27001
* Assigning improvement actions to owners
* Granting least-privilege access to an assessment
* Documenting security work clearly, with evidence
* Creating a custom sensitive info type and retention label
* Auto-applying labels with a policy
* Auditing existing retention labels with Security & Compliance PowerShell
* Creating an organization-wide retention policy
* Auto-applying a retention label using a built-in sensitive info type
